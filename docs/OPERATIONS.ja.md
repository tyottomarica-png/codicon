# Codicon 操作ガイド

Codicon は、Xbox コントローラを **Claude Code / Codex の操作面（コントロールサーフェス）** にするデスクトップアプリです。[Codex Micro マクロパッド](https://openai.com/supply/co-lab/work-louder/)のソフトウェア版だと考えてください。

**Codicon 自身にはチャット画面がありません。** 会話は普段お使いのアプリで読み書きします。Codicon が担うのはマクロパッドと同じ役割です。

- **Agent Keys**: 動いているエージェントを全部並べ、それぞれのランプで状態（思考中 / 実行中 / 要対応 / 未読）を一目で示します。
- **ダイヤル**: LB を押しながらスティックでモデルと推論量。
- **ジョイスティック**: LT を押しながらスティックで Skill（PRレビュー、デバッグ、リファクタ等）を起動。
- **コマンドキー**: 承認・拒否・中断・Push to Talk・新規エージェント。

Linux と macOS で同じ標準 Gamepad マッピングを使用します。

## 最初に行うこと

1. 使いたいエージェントにサインインします。Codex は `codex login`、Claude Code は `claude login`。どちらか片方だけでも使えます（もう片方は「利用不可」と理由が表示されます）。
2. Xbox コントローラを USB または Bluetooth で接続します。
3. Codicon を起動し、上部中央のワークスペース名から作業対象フォルダを選びます。
4. 画面右上が `AGENT ONLINE`、コントローラ表示が `PAD READY` になれば準備完了です。

macOS では初回の Push to Talk 時にマイク権限を許可してください。Codicon がマイクを使用するのは Push to Talk 中だけです。

## ターゲット（操作対象エージェント）

コントローラは常に「アクティブターゲット」を操作します。ステータスバー左上のバッジに現在のターゲット（CODEX / CLAUDE）と判定方法が表示されます。

- **Auto（既定）**: 前面のアプリを監視して自動で切り替えます。ターミナルのアクティブタブで `claude` が動いていれば Claude、`codex` なら Codex。Claude デスクトップアプリが前面のときも Claude です。判定できないときは直前のターゲットを維持します。
- **手動**: **VIEW ボタン**でいつでも切り替えられます（Auto は解除され手動固定になります）。メニューバーのアイコン、ステータスバーのバッジ、Settings からも変更できます。
- ターミナルのアクティブタブ判定には、初回のみ macOS の「オートメーション」許可（Codicon → Terminal / iTerm2）を求められます。拒否しても全体のプロセス走査で近似判定します。

各バックエンドは独立したセッションを持ちます。ターゲットを切り替えても、それぞれの会話・スレッドは失われません。

### リングを他のアプリの上で使う

Claude Code や Codex のウィンドウを前面にしたまま **LB（Power Ring）や LT（Skills Ring）を押すと、画面中央に同じデザインの円形セレクタがオーバーレイ表示**されます。スティックで選び、離して確定。クリックを奪わない表示専用ウィンドウなので、作業中のアプリの操作を妨げません。

## ダイレクト操作（開いているアプリを直接動かす）

既定では、リングの操作は Codicon 自身が持つセッションに効きます。**ダイレクト操作**をオンにすると、同じリングが**いま前面で開いている Claude / Codex そのもの**に効くようになります。物理マクロパッドと同じ挙動です。

**Settings → Direct control** で切り替えます。

| モード | 動作 | 必要な権限 |
| --- | --- | --- |
| `clipboard` | コマンドをクリップボードに置きます（⌘V で貼り付け） | **なし** |
| `type` | 前面のエージェントに実際にキー入力を送ります | macOS のアクセシビリティ |

`type` を使うには入力モジュールも必要です: `npm install @jitsi/robotjs`（Node-API、macOS/Linux のプリビルド同梱、コンパイル不要）。

安全側の作りは設定ではなく構造で担保しています。

- **既定はオフ。** 明示的に有効化するまで何も送りません。
- **1回の押下につき1回の送信。** タイマー・再送・キューは一切ありません。すべての送信が物理的なボタン操作に1対1で対応します。
- **送信直前に前面アプリを再確認。** リングで選んでからトリガーを離すまでの間にブラウザやパスワードマネージャへ切り替えていた場合、そこへ入力せずに**送信を中止**します。
- **連続送信の抑制。** ボタンが張り付いても入力の奔流にはなりません。
- 何を送ったか、送れなかったならなぜかを画面に表示します。

### 各CLIが実際に受け付けるもの

推測ではなく実測しています。**Claude Code** は `/model`、`/effort`、`/fast` すべてに引数を直接渡せます。**Codex** は渡せません — upstream の `codex-rs/tui/src/slash_command.rs` にある `supports_inline_args()` の許可リストに `Model` と `Permissions` が含まれていないためです。したがって Codex では `/model` で**ピッカーを開くところまで**を行い、選択はあなたが行います（矢印キーを送る実装にすると、候補の並びが変わったときに黙って別のモデルを選んでしまうため）。

## Skills Ring

LT を押しながら左スティックで、登録済みの作業を選んで起動します。既定では PRレビュー / デバッグ / リファクタ / テスト追加の4つが入っています。スティックを倒さずに離した場合は何も起動しません。

内容は Settings > Skills で自由に編集・追加できます。送られるのは登録したプロンプト文そのものなので、「このリポジトリの規約に沿って〜」のようにプロジェクト固有の指示を書いておくと便利です。

## 画面の見かた

Codicon にチャット欄はありません。代わりに次の3つで状況を把握します。

- **Power / Skills リング**（左）: 現在のモデル・推論量・速度。
- **Agent Keys**（中央）: 動いている全エージェントとランプ。灰=待機、紫=思考中、橙=ツール実行中、黄=要対応、緑=未読の返答あり、赤=エラー。行をクリックすると操作対象が切り替わります。
- **READOUT**（右）: 選択中エージェントの実行中ツールと、直近の返答の末尾。

## Power Ring

Power Ring は3種類の値を分けて扱います。

- モデル: LBを押しながら左スティックの方向で選択します。Codex ターゲットでは Sol / Terra / Luna など、Claude ターゲットでは Fable / Opus / Sonnet などを既定で割り当てています。候補は各 CLI から動的に取得します。
- 推論量: LBを押しながら右スティックの方向で選択します。Codex はモデルが公開する推論量（Low〜Ultra）、Claude は effort（Low / Medium / High / Extra High / Max）です。
- 速度: RS押し込みで Fast をオン/オフします。Codex は service tier（`priority`）、Claude は `/fast` 相当のフラグ設定（対応モデルのみ）を使用します。

LBを離すと、左右スティックでプレビューしていたモデルと推論量が同時に確定します。LBを押している最中にBを押すと変更をキャンセルします。選択が変わるたびに対応コントローラでは短いハプティックフィードバックが鳴ります。

Max は1つのエージェントにより長く考えさせる設定です。Ultra は複数エージェントを積極利用する設定です。Fast は速度優先の service tier であり、この2つとは独立しています。

## 音声で指示する

音声入力は Codex ターゲットでのみ利用できます（Claude Code にはリアルタイム音声APIがないため）。RBを押し続けて話し、話し終えたら離します。マイク入力は24 kHz・モノラル・16-bit PCMに変換され、Codex app-server のリアルタイム音声セッションへ送られます。別の OpenAI API キーは不要です。

RBを離すと文字起こしが Codex に引き渡され、通常のターンとしてツール実行やファイル編集が進みます。進行状況は READOUT 欄と Agent Key のランプで確認できます。

リアルタイム音声は現行 Codex app-server では実験的機能です。接続できない場合は画面下部に理由を表示します。

## そのほかの既定ボタン

| ボタン | 動作 |
| --- | --- |
| A | 承認ダイアログの「今回のみ許可」、質問の推奨回答 |
| B | 実行中ターンの中断、承認拒否、Power Ringのキャンセル |
| X | Codicon を前面に表示 |
| Y | 新規セッション。以前のセッションは各エージェントの履歴に残ります |
| LB（ホールド） | Power Ring（モデル / 推論量） |
| LT（ホールド） | Skills Ring（保存した作業を起動） |
| RB（ホールド） | Push to Talk（Codexターゲットのみ） |
| RS（クリック） | Fast 切り替え |
| VIEW | ターゲット切替（Codex ⇄ Claude） |
| Menu | 設定パネル |

すべてのボタン割り当てとスティックのデッドゾーンは Settings > Xbox mappings で変更できます。スティックドリフトが強い場合は deadzone を上げてください。コントローラ操作を完全に無効化するスイッチもあります。

## 背景で動かす

Codicon はコントローラ入力を Electron のメインプロセスで SDL 経由で直接読み取ります。ブラウザの Gamepad API と違いフォーカスを必要としないため、**Codex CLI や Claude Code のウィンドウを前面にしたままでも、上記のボタン操作はすべて効きます**。

- ステータスバーに `BG` バッジが出ていれば、背景入力が有効です。
- メニューバー（Linux ではトレイ）のアイコンからウィンドウの再表示、ターゲットの切り替え、オーバーレイの切り替え、終了ができます。
- ウィンドウを閉じてもセッションは終了せず、常駐状態になります。完全に終了するにはメニューバーの Quit を使ってください。この挙動は Settings > Background operation で変更できます。

### ステータスオーバーレイ

小さなオーバーレイが常に最前面に表示され、現在のモデル・推論量・ターンの状態（WORKING / LISTENING / NEEDS APPROVAL）を示します。フォーカスを奪わないので、他のアプリでの入力を妨げません。ドラッグで移動でき、位置は記憶されます。⤢ ボタンでメインウィンドウを前面に戻せます。

macOS のフルスクリーン領域の上にも表示されます。不要な場合は Settings > Background operation か、メニューバーのチェックボックスから消せます。

### macOS の権限

macOS がコントローラ入力をアプリに渡すために、**システム設定 > プライバシーとセキュリティ > 入力監視** で Codicon を許可する必要がある場合があります。ステータスバーが `INPUT OFFLINE` のまま、またはボタンが背景でだけ効かない場合はここを確認してください。

なお macOS 15.4 には背景でのコントローラ入力が壊れる不具合がありましたが、[Apple により 15.5 で修正済み](https://developer.apple.com/forums/thread/780929)です。15.4 を使っている場合はアップデートしてください。

## 承認と安全設定

既定は `Auto` です。エージェントはワークスペース内を読み書きでき、範囲外の操作では承認を求めます。承認ダイアログは両バックエンド共通で、Aが「今回のみ許可」、Bが「拒否」です。

- Read Only: コードを読み取って相談・計画する用途。Codex は read-only サンドボックス、Claude は plan モードになります。
- Auto: Codex は `workspace-write` + `on-request`、Claude は既定の権限モード + 承認プロンプト。通常利用の推奨値。
- Full Access: サンドボックス/権限確認を外します（Codex `danger-full-access` / Claude `bypassPermissions`）。信頼できるリポジトリでのみ使用してください。

Full Access は Settings からしか選べず、Power Ring や単一のコントローラ誤入力では有効になりません。コマンド・ファイル変更の承認には、実行内容と理由が表示されます。

## モデルプリセットを変える

Settings に Codex 用と Claude 用のプリセットが別々にあります。3方向の各枠に、各 CLI から返った任意のモデルを割り当てられます。モデル名や推論オプションは固定リストではなく起動中の CLI から取得するため、新しいモデルもアプリ更新なしで候補に現れます。

## 配布物

Linux x64 では次を実行できます。

```bash
chmod +x Codicon-0.1.0-linux-x86_64.AppImage
./Codicon-0.1.0-linux-x86_64.AppImage
```

macOS の DMG/ZIP は macOS 上で `npm run dist:mac` を実行するか、同梱の GitHub Actions workflow から生成します。SDL のネイティブバイナリはインストール時にそのマシンのアーキテクチャ向けに取得されるため、`dist:mac` は**実行したマシンのアーキテクチャ分だけ**を生成します。x64 と arm64 の両方が必要な場合は、workflow が Apple Silicon と Intel のランナーでそれぞれビルドします。第三者へ配布する際は Apple Developer ID 署名と notarization を設定してください。

## トラブルシューティング

- `AGENT UNAVAILABLE`（Codex）: Settings の codex path を確認し、ターミナルで `codex doctor` を実行します。macOSのGUI起動ではPATHが短いため、Codiconは `~/.local/bin/codex` と Homebrew の標準パスも検索します。
- `AGENT UNAVAILABLE`（Claude）: `claude login` でサインインしているか確認します。通常は SDK 同梱の claude バイナリを使うため PATH 設定は不要です。挙動を変えたい場合は Settings の claude path に手元のバイナリを指定できます。
- ターゲットが切り替わらない: Auto 判定はターミナルのアクティブタブの前面プロセスを見ます。tmux やネスト環境では判定できないことがあるため、VIEW ボタンで手動固定してください。
- `NO GAMEPAD`: OSのゲームコントローラ設定で接続を確認し、一度ボタンを押します。標準マッピングでない機種はボタン番号をSettingsで調整します。
- `INPUT OFFLINE`: SDL のコントローラ読み取りを開始できていません。ステータス表示にカーソルを合わせると理由が出ます。macOS では「入力監視」の許可を確認してください。
- 音声エラー: OSのマイク権限、Codexへのサインイン、ネットワーク接続を確認します。`CODEX_SMOKE_VOICE=1 npm run smoke:codex` で音声セッションとPCM受信だけを確認できます。
- Linuxの開発版が `chrome-sandbox` で停止: ElectronのLinux sandbox手順に従って開発バイナリの所有者・modeを設定します。配布ランチャーに `--no-sandbox` を埋め込まないでください。

Codex連携は公式の [app-server protocol](https://github.com/openai/codex/blob/main/codex-rs/app-server/README.md) を使用しています。
